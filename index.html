What this is. A settlement model, not a crystal ball. Every tick it bootstraps thousands of price paths from BTC's own recent 1-minute returns and counts how many close above your strike — then a logistic layer that has been trained on this app's own settled windows adjusts that number, and a calibration term scales it back if the model has been running hot. Confidence is a probability, so it is allowed to be high when price is far from the strike near the close, and it is allowed to be near 50 when the window genuinely is a coin flip. SKIP only fires inside the coin-flip band set by the risk dial — turn the dial up and the band closes to zero. Price is Coinbase BTC-USD spot and can differ from Kalshi's settlement index. Nothing here is financial advice.
